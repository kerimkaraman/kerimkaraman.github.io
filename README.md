# Kerim Karaman — Portfolio

Y2K / soft club estetiğinde, İngilizce kişisel AI engineer portfolyosu. Proje açıklamaları Keryon kaynakları ve Model Router değerlendirme raporlarına dayanır.

## Yerel önizleme

`npm run dev` ile http://localhost:5173 adresini açın. Bağımlılık kurulumu veya derleme gerekmez. Yayın dosyaları `dist/` içindedir.

## İçerik

Mobil uyumlu tasarım, kişisel ilgi alanları, Model Router + Eval sonuçları, Keryon ve Simple RAG Chatbot proje notları, klavyeyle kullanılabilir RAG açıklayıcısı. İletişim adresi verilmediği için e-posta veya sosyal hesap bağlantısı eklenmedi.

## GitHub Pages

Site adresi: https://kerimkaraman.github.io/

`main` dalına yapılan push, GitHub Actions üzerinden yalnızca `dist/` klasörünü yayınlar. Repository Settings → Pages → Source ayarı **GitHub Actions** olmalıdır. `docs/` ve `.openai/` yerelde tutulur ve public repoya gönderilmez.
